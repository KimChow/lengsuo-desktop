# 任务书 · d3-workbench-layout（工作台三区布局骨架）

## 目标

实现 参照平台语义的**三区布局**：左边栏（会话列表）+ 中间会话流 + 右侧面板（任务/预览/审批）。

## 参考事实（来自产品逆向文档，权威）

三区布局的原文描述：

```
┌──────┬──────────────────────────────┬────────────┐
│ 边栏  │        会话流                 │ 右侧面板     │
│ 260px │ 用户/AI消息/工具卡片           │ 任务/预览/   │
│ 会话  │──────────────────────────────┤ 审批待办     │
│ 列表  │ 输入区(多行+模式选择+发送)      │ (可折叠)    │
└──────┴──────────────────────────────┴────────────┘
```

关键约束（逐条实现，不要自行简化）：

1. **边栏宽 260px**，含会话列表（置顶/归档/未读状态）
2. **右侧面板三 tab**：任务清单 / 文件预览 / 审批待办，**可折叠**
3. **输入区**：多行输入 + 模式选择（5 模式）+ 发送按钮
4. 三区**可调整宽度**（右侧面板可折叠即最小实现）

## 与既有状态层的对接

**先读** `crates/lengsuo-desktop/src/state/session_stream.rs`，里面有：

- `SessionStreamState`：消息列表 + 审批 + seq 单调校验 + 断档标记
- `MessageRole` 四类：`User` / `Assistant` / `ToolCall` / `ToolResult`
- `pending_approvals()`：未决策的审批项

布局**只消费这些状态**，不自己造数据、不复制一份 state。

## 你要做的事

1. 在 `src/ui/` 下新建布局模块（建议 `layout.rs` + `sidebar.rs` + `right_panel.rs`）
2. 实现三区骨架，每个区域先渲染**占位内容**（文字说明即可）
3. 把 `SessionStreamState` 接进会话流区：渲染消息列表（暂不做富文本）
4. 右侧面板做三 tab 切换（用本地 UI state，不接业务）

## 参考写法

**读** `src/state/env_list.rs` 与 `src/state/org.rs`，看本仓状态层的写法：
字段私有、方法访问、三态区分、判定收进状态层。布局同理 ——

- 布局的**尺寸/折叠/tab 选中**这些 UI 状态，要定义成结构体（放 `layout.rs` 或独立 state 文件）
- 不要在渲染函数里散落硬编码状态

## 交付物

1. `src/ui/` 下新增的布局文件
2. `docs/workbench-layout-status.md`：文件清单、实跑命令与退出码、缺口

## 边界

- 只改 `src/ui/` 下**新建的**文件 + `ui/mod.rs` 追加 `pub mod`
- **不改** `src/state/`、`src/theme/`、`Cargo.toml`
- 不接真实数据源；用现有 state 类型构造测试数据即可
- 不做富文本渲染（Markdown / diff 另卡）

## 完成标准

1. 三区布局可渲染（或至少 `cargo check --features ui` 通过）
2. 右侧面板三 tab 可切换
3. 布局状态收在结构体里，不散落硬编码
4. 门禁四项全绿（不开 `ui` 时也必须绿）

## ⛔ 上游不可用时的行为（硬约束）

若你在执行中遇到以下任一情况，**立即停止重试并结束本轮**，不要反复重试、不要改写任务目标：

- `API Error: 403` / `Failed to authenticate` / `上游模型繁忙`
- `API returned an empty or malformed response` / `check for a proxy or gateway`
- 连续两次工具调用均因网络/网关错误失败

结束时的报告必须是：

```
STATUS: UPSTREAM_UNAVAILABLE
最后一次错误原文：<粘贴>
已完成的工作：<无 或 具体文件列表>
```

**理由**：历史上有卡因 403 空转 61 轮、零产物、整轮作废。宁可快速失败让主理人修网关，也不要把轮次消耗在重试上。**这不是你的错，如实上报即可。**
