# 任务书 · d1-ime-win32-recon（IME 缺陷取证与修复方案）

## 本卡定位：**调研卡（只读，不编码）**

产出是一份**可执行的修复方案文档**，不是代码。下一张卡（`d2-ime-fix`）才动手改。

## 背景

本仓将用 GPUI + gpui-kit 做桌面界面。GPUI 在 Windows 上有两条已确认的中文输入法（IME）缺陷，
是**中文产品的硬阻塞**：主界面的会话输入框、搜索框都要用中文输入。

已知的两条 issue：

| Issue | 症状 |
|---|---|
| zed-industries/zed **#56327** | `WM_KEYDOWN` 路径不检查 IME 组合态 → 汉字重复插入；另有 `direct_write.rs` 多字节切片 panic |
| zed-industries/zed **#64850** | IME 定位只给一个点（`y = origin.y + height/2`）+ `CFS_CANDIDATEPOS` 无排除区 → 候选框盖住正在输入的字 |

## 你要做的事

### 1. 取证：确认缺陷在本机可复现

**必须先做这一步，不许跳过。**

1. 建一个最小 GPUI 工程（`/tmp/ime-probe`，不入仓），依赖 `gpui = "0.2.2"`（若 crates.io 拉不到就试 gpui-kit）。
   - 若能联网：`cargo add gpui`。若被限制，记录实际报错，改用 `gpui-kit` 或 `gpui-pre` 试。
2. 放一个多行文本输入框，编译运行。
3. **用中文输入法实际输入**（如果你无法交互输入，就用 `SendInput` 或脚本模拟，或明确记录「无法交互验证」）。
4. 记录：**实际观察到的行为**（崩溃？重复字符？候选框位置？），逐条与上面两条 issue 的症状对照。

⚠️ 若设备无法交互输入（headless），**必须如实写明「未能实测」**，并把这一项标为未验证。
**不得**把「读 issue 描述」写成「已复现」。

### 2. 定位源码：找到要改的确切位置

在 GPUI 源码里找到：

- IME 消息处理：搜 `WM_IME`、`WM_KEYDOWN`、`handle_keydown_msg`、`handle_char_msg`、`parse_char_message`
- IME 定位：搜 `ImmSetCandidateWindow`、`CFS_CANDIDATEPOS`、`update_ime_position`、`retrieve_caret_position`
- 多字节切片：搜 `direct_write.rs` 里的 `TextRun` / `shape_line` / `layout_line`

对每一处，报告 **文件路径 + 行号 + 代码原文片段 + 它现在错在哪**。

GPUI 源码获取方式（任选其一，记录实际用的）：
- `cargo vendor` 后本地读
- 从 `~/.cargo/registry/src/` 读已下载的 `gpui` / `gpui-pre` 源码
- 若以上都不行，读 gpui-kit 仓库里的 vendored 副本

### 3. 写修复方案（核心产出）

对每条缺陷给：

| 项 | 要求 |
|---|---|
| 根因 | 一句话说清「为什么会这样」，附源码位置 |
| 修法 | 具体到改哪个函数、加什么判断。IME 定位那条的正解方向是 `CFS_EXCLUDE` + `rcArea` 传 caret 矩形（不是单点） |
| 改动面 | 预计改哪些文件、多少行 |
| 风险 | 这个改动可能影响什么（如输入法兼容性、其他平台） |
| 验证方法 | 改完**怎么证明修好了**——要可执行、可复现的步骤 |

### 4. 判断：修在哪里

三条路，给推荐并说明理由：

| 选项 | 说明 |
|---|---|
| A. 改本地 vendored 的 gpui 源码 | 完全掌控，但跟上游脱节 |
| B. fork gpui-kit 并向上游 PR | 社区共享，但依赖对方合并节奏 |
| C. 在应用层绕过（如用 WebView 承载输入框） | 不改底层，但 §1.5b 已限定 WebView 面积 |

## 交付物

`docs/ime-win32-recon-status.md`，包含：

1. 复现结果（**如实**：复现了 / 未能实测 / 部分复现）
2. 源码定位表（文件 + 行号 + 原文 + 错在哪）
3. 逐条修复方案（根因 / 修法 / 改动面 / 风险 / 验证方法）
4. 修在哪里的推荐与理由
5. 给下一张卡（`d2-ime-fix`）的具体指令清单
6. **未验证项清单**（诚实列出哪些是读来的、哪些是实测的）

## 边界

- 探针工程放 `/tmp`，**不入仓**。
- 参考源：`~/ref/reference-docs`（若需产品行为参考）。GPUI 源码按上面第 2 节的方式获取。
- 允许 `touches`：`docs/ime-win32-recon-status.md`
